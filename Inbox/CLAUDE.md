# Inbox

> Chargé automatiquement par Claude Code quand on travaille dans ce dossier.

## Rôle
Zone tampon de capture unique. Tout ce qui arrive sans place définie atterrit ici : idées, transcripts à trier, fichiers déposés, captures web. Un sas, pas un stockage.

## Règle
Rien ne reste ici plus de quelques jours. On vide avec `/inbox-processor`, qui route chaque item vers le bon dossier (`Projects/<Domaine>/`, `Contexte/`, `Intelligence/wiki/`) ou l'archive.

## Ne va PAS ici
- Les livrables finis (`Projects/<Domaine>/output/`)
- Les sources du wiki (`Intelligence/raw/`)

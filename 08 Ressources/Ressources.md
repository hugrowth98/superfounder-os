# Ressources

> Ce qui aide à produire mais n'est pas un livrable ni une note de travail : templates, exemples, docs d'outils, et la veille.

## Organisation

- `templates/` : les modèles de note (projet, département, client), de journal (jour, semaine), de réflexion et de livrable. Toute nouvelle note part d'un de ces fichiers.
- `Veille/` : ce qui vient de l'extérieur. `sources/` pour le brut immuable, `wiki/` pour les pages de connaissance écrites par `/notes-permanentes`.
- À plat : vos exemples de bons contenus, docs d'API, kits de marque tiers.

## Règles

- Une ressource n'a pas de section Où on en est : elle se lit, elle ne se pilote pas.
- Un asset propre à un client, un projet ou un département vit chez lui, pas ici.

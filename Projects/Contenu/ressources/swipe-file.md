## Ce qu'on emprunte et ce qu'on ne copie pas

Emprunter : les structures (avant/après, liste avec sous-points, hook + 3 arguments + conclusion), les patterns de hooks, les marqueurs visuels, l'angle d'un sujet.

Ne jamais copier : les mots exacts, les histoires personnelles d'un autre, des chiffres qui ne sont pas les vôtres, le positionnement d'une autre personne.

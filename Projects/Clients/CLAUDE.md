# Clients

> Chargé automatiquement par Claude Code quand on travaille dans ce dossier. Le bloc ETAT est maintenu par /done : ne pas l'éditer à la main.

## Rôle
Tout ce qui est produit pour un client précis : livrables, comptes rendus, propositions, suivi de mission. Un client qui prend de la place mérite son propre sous-dossier `Clients/<NomClient>/` avec le même patron (CLAUDE.md, _journal.md, input/ output/ ressources/).

## Conventions
- Chaque livrable est préfixé du nom du client : `NomClient_Sujet_YYYY-MM-DD.ext`.
- Ce qui vient du client (brief, transcript, export) va dans `input/`. Ce qu'on lui livre va dans `output/`.
- Le contexte propre à un client (ses enjeux, ses interlocuteurs, l'historique) vit dans le CLAUDE.md de son sous-dossier, jamais dans `Contexte/` (qui décrit votre activité, pas la sienne).

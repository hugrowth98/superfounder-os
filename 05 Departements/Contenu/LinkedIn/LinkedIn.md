# LinkedIn

## Mission

Tout post LinkedIn, même lié à un client, plus les drafts, les briefs visuels, les carrousels, les infographies et le calendrier éditorial. Les posts vont dans `livrables/`, un fichier par post.

`ressources/` porte les trois fichiers que tous les skills de contenu lisent : `strategie-contenu.md` (piliers, convictions, sources), `posts-de-reference.md` (vos posts, pour caler la voix), `swipe-file.md` (les posts des autres, pour les structures).

Ne va pas ici : les messages de prospection envoyés en DM (`05 Departements/Go-to-Market/Messages/`), la source qui a inspiré le post (`08 Ressources/Veille/sources/`).

## Cadre

Un post par fichier : `Post-Sujet_YYYY-MM-DD.md`. Le brief de veille hebdo : `Brief-veille_YYYY-MM-DD.md`. Les sources (transcripts, articles, idées brutes) dans `sources/`.

Les posts qui ont bien marché remontent dans `ressources/posts-de-reference.md`. Les posts des autres qui arrêtent le scroll vont dans `ressources/swipe-file.md`. Plus l'échantillon est riche, plus la voix est juste.

- `livrables/` un fichier par post
- `sources/` transcripts, articles, idées brutes à repurposer
- `ressources/` strategie-contenu.md, posts-de-reference.md, swipe-file.md

# Checklist qualite - Posts LinkedIn

## Avant publication : 15 points de controle

### Hook (5 points)
- [ ] La premiere ligne arrete le scroll (thumb-stop test)
- [ ] Le hook tient en 2-3 lignes max (avant "voir plus")
- [ ] Il combine au moins 2/3 : curiosite, ciblage, promesse
- [ ] Pas de clickbait - le hook est aligne avec le contenu reel
- [ ] Pas d'emoji en ouverture (sauf exception rare et justifiee)

### Structure (4 points)
- [ ] Formate pour lecture mobile (paragraphes courts, sauts de ligne)
- [ ] Utilise les symboles → ↳ pour structurer (pas de bullet points markdown)
- [ ] Maximum 2-3 listes dans le post
- [ ] Longueur adaptee au format (1500-2500 car. pour un texte, peut aller jusqu'a 3000)

### Contenu (4 points)
- [ ] Une seule idee principale, bien developpee
- [ ] Base sur un insight concret, une experience, un resultat (pas du generique)
- [ ] Le lecteur repart avec quelque chose (actionnable, reflexion, inspiration)
- [ ] Les exemples sont specifiques (noms d'outils, chiffres, contexte)

### Voix (2 points)
- [ ] Sonne comme toi : direct, concret, pas de jargon inutile
- [ ] Ton approprie au type de contenu (expert/intime/direct selon le cas)

## 5 questions avant de cliquer "Publier"

1. **"Est-ce que je cliquerais sur 'voir plus' ?"** - Si le hook ne te donne pas envie, recommence.
2. **"Qu'est-ce que le lecteur retient ?"** - Si tu ne peux pas resumer en 1 phrase, le post manque de focus.
3. **"Est-ce base sur MON experience ?"** - Le contenu doit venir de ce que tu as vecu, teste, observe.
4. **"Est-ce que ca sonne humain ?"** - Lis a voix haute. Si ca sonne robotique, recris.
5. **"Quel est le dwell time potentiel ?"** - Le post doit retenir l'attention (infographie, liste, histoire, open loops).

## Red flags - A corriger immediatement

| Red flag | Correction |
|----------|-----------|
| Plus de 3 emojis | Reduire a 0-1 |
| Paragraphe > 3 lignes | Couper en morceaux |
| "Revolutionnaire", "game-changer" | Supprimer ou remplacer par un fait concret |
| Ouverture par "Et si je vous disais..." | Reecrire le hook |
| Pas de CTA ni question finale | Ajouter une question engageante |
| Ton "coach de vie" motivationnel | Revenir au concret et au terrain |
| Post 100% theorique sans exemple | Ajouter un cas concret, un chiffre, un outil |
| Storytelling artificiel force | Raconter simplement ce qui s'est passe |
| Post en anglais (sauf demande) | Traduire en {{LANGUAGE}} |
| Hook > 3 lignes | Raccourcir, aller droit au but |

# Marketing

## Rôle

Tout ce qui fait venir des gens : contenu, events, campagnes, publicités, community. C'est le dossier de la distribution. Le module de contenu de Superfounder OS y vit : dix skills de contenu dans `Skills/` à la racine, un socle commun (`linkedin-writing-core`) que tous les autres chargent en premier.

Six briques, chacune avec sa note :

- `LinkedIn/` : les posts, carrousels, infographies, le calendrier éditorial. Les ressources de contenu (stratégie, posts de référence, swipe file) vivent dans `LinkedIn/ressources/`
- `Newsletter/` : les éditions et leurs archives
- `Mailing/` : les emails à l'audience déjà inscrite (promo d'event, nurturing, annonces)
- `Event/` : les lives, webinaires et challenges, un dossier daté par event
- `Video/` : les vidéos publiées, pubs en tête
- `Slides/` : les supports visuels transverses et les ateliers livrés

Ne va pas ici : une propale ou un message de prospection (`Vente/`), un livrable pour un client précis (`Produit-Client/`), une réflexion sur l'offre ou le pricing (`Strategie/`).

## Conventions

**Contexte à charger avant d'écrire.** Aucun skill de ce dossier ne contient de donnée sur l'utilisateur. Avant de rédiger quoi que ce soit : `Contexte/Tone-and-Voice.md` et `About-Me/anti-ai-voice.md`, `Contexte/Offer-Positioning.md`, `Contexte/Clients-Problems-and-Messages.md`, puis `LinkedIn/ressources/strategie-contenu.md`, `posts-de-reference.md` (l'échantillon l'emporte sur les principes) et `swipe-file.md`. Si `strategie-contenu.md` ou un fichier de `Contexte/` contient encore `[à remplir]`, dis-le et propose "Installe mon contenu" (ou "Installe mon second cerveau").

**Premier message dans ce dossier.** `LinkedIn/ressources/strategie-contenu.md` encore `[à remplir]` : bienvenue en 2 phrases, puis `installer-contenu`. Installé : lis le bloc ETAT et propose la prochaine action (un post à écrire, la veille de la semaine, un post à optimiser).

**La chaîne en 5 stations**

| Station | L'utilisateur écrit | Skill |
|---|---|---|
| 1. Trouver quoi dire | "idées de posts", "fais ma veille", "interviewe-moi" | `linkedin-ideation`, `linkedin-interview` |
| 2. Le socle | (chargé automatiquement par les skills de rédaction) | `linkedin-writing-core` |
| 3. Écrire dans le bon format | "écris un tuto sur", "raconte", "mon avis sur", "post lead magnet" | `linkedin-educational`, `linkedin-storytelling`, `linkedin-hot-take`, `linkedin-lead-magnet` |
| 4. Maximiser la portée | "propose des hooks", "améliore ce post" | `viral-hook-writer`, `linkedin-post-optimizer` |
| 5. Installer ou réinstaller | "Installe mon contenu" | `installer-contenu` |

Si le type de post n'est pas précisé, `linkedin-writing-core` choisit le format puis charge le skill spécialisé.

**Règles.** Le support final l'emporte sur le sujet : un post qui annonce un event va dans `LinkedIn/`, l'email d'invitation dans `Mailing/`, les slides de l'event dans son dossier `Event/<Event>/`. Toute initiative datée (event, lancement) devient un sous-dossier avec sa note et part dans `Archives/` quand elle est finie. Vouvoiement sur tout contenu publié, sauf si `Contexte/Tone-and-Voice.md` dit le contraire. Aucun tiret cadratin dans un post.

## Organisation

- `Video/` vidéos publiées
- `Slides/` supports Excalidraw transverses
- les 10 skills de contenu vivent dans `Skills/` à la racine, visibles partout

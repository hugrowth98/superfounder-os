## 1. Principes generiques d'une bonne voix LinkedIn

### Le rythme
Une voix LinkedIn efficace s'ecrit avec un rythme rapide. Les phrases sont courtes. Elles claquent. Le developpement arrive quand c'est necessaire - jamais plus de 2-3 lignes d'affilement.

Pattern typique :
```
[Phrase courte percutante.]

[Developpement en 2 lignes max.]

[Phrase de transition courte.]

-> Point 1
-> Point 2
-> Point 3

[Conclusion directe.]
```

### Les transitions
Mots de liaison simples et directs qui marquent une voix authentique :
- "Bref," (pour conclure un raisonnement)
- "Resultat ?" ou "Resultat :" (pour montrer l'impact)
- "Concretement," (pour atterrir dans le concret)
- "Le probleme ?" (pour introduire une tension)
- "Et si" (pour ouvrir une reflexion)
- "Pourquoi ?" (pour expliquer)
- "La bonne nouvelle ?" (pour pivoter vers le positif)

### Le vocabulaire
Une bonne voix LinkedIn prefere le vocabulaire de terrain plutot qu'academique :
- "systeme" plutot que "processus strategique"
- "ca marche" plutot que "cela s'avere performant"
- "tester" plutot que "experimenter"
- "mettre en place" plutot que "implementer"
- "resultat" plutot que "outcome" (sauf en contexte tech)
- "rendez-vous" plutot que "meeting qualifie"
- "ton business" plutot que "votre entreprise" (tutoiement naturel)

### Marqueurs visuels de structure (generiques, a adapter)
```
->    listes de features, benefices, etapes
->    sous-points, details, explications
1️⃣ 2️⃣ 3️⃣    etapes numerotees, processus
✅    resultats, benefices valides
"Bref,"    conclusion de demonstration
Question finale    engagement CTA
"Et vous..." / "Et toi..."    CTA commentaire ou connexion
```

## 3. Anti-patterns a eviter

### Ne jamais ecrire comme ca :
```
Trop d'emojis + buzzwords vides + ton "vendeur de reve" :
❌ "Vous voulez EXPLOSER vos resultats ?
Decouvrez cette methode REVOLUTIONNAIRE qui va TRANSFORMER votre business !"
```

```
Promesse irrealiste + ton "guru" + fausse question rhetorique :
❌ "Et si je vous disais qu'il existe une methode simple, efficace et prouvee
pour doubler votre chiffre d'affaires en 30 jours ?"
```

```
Introduction generique, pas de hook, pas d'angle :
❌ "Dans un monde en constante evolution, les entrepreneurs doivent s'adapter
aux nouvelles technologies pour rester competitifs..."
```

```
Fausse humilite + buzzword anglais gratuit :
❌ "J'ai la chance incroyable de pouvoir partager avec vous
ce framework absolument game-changing..."
```

### Comment ecrire a la place :
```
Concret, honnete, curiosite :
✅ "J'ai teste [X] methodes en [Y] mois.
[N] ont vraiment fonctionne. Voici lesquelles."
```

## 4. Adaptation selon le type de contenu

### Contenu autorite (split principal - voir le mix autorité / perso / offre de `Marketing/LinkedIn/ressources/strategie-contenu.md`)
- Ton : expert mais accessible
- Base sur l'experience vecue, pas sur la theorie
- Inclut des exemples concrets, des chiffres, des noms d'outils
- Le lecteur repart avec quelque chose d'actionnable

### Personal brand (split secondaire)
- Ton : plus intime, vulnerable par moments
- Partage des doutes, des echecs, des apprentissages
- Humanise le createur - montre l'homme/la femme derriere l'expert
- Ne tombe jamais dans le miserabilisme

### Contenu offre (split minoritaire)
- Ton : direct, oriente resultat
- Utilise les frameworks PAS, BBA ou CPF
- Montre le resultat du client, pas les features de l'offre
- CTA clair et simple

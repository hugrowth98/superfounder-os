# Branding

## Mission

La référence visuelle : charte, palette, typographie, logos, polices, brand book. Ce que tout visuel produit doit respecter.

Ne va pas ici : les visuels produits (ils vont dans `05 Departements/Contenu/`), les supports d'un event (dans son dossier).

## Cadre

Une seule charte à la fois. Les fichiers binaires (logos, polices) vivent ici mais ne se versionnent pas dans un dépôt public. Une ligne dans cette note suffit pour commencer : vos couleurs et votre police.

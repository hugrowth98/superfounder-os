# Propositions

## Mission

Les propositions commerciales envoyées : propales, devis, et les mails qui les accompagnent.

Ne va pas ici : la réflexion sur l'offre ou le prix (`05_Departements/Strategie/`), le livrable produit une fois la mission signée (`06_Clients/<Client>/`).

## Cadre

Nommage `Propale-<Client>-<Sujet>_YYYY-MM-DD`. Le mail d'envoi porte le même préfixe.

Les prix viennent de `01_About-Me/my-company.md`, jamais redéfinis ici. Une propale envoyée ne se modifie plus : une nouvelle version porte une nouvelle date, l'ancienne va dans `11_Archives/`.

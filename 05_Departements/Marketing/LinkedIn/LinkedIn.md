# LinkedIn

## Mission

Tout post LinkedIn, même lié à un client, plus les drafts, les briefs visuels, les carrousels, les infographies et le calendrier éditorial. Un fichier par post, à plat dans ce dossier.

Trois fichiers que tous les skills de contenu lisent vivent ici aussi : `strategie-contenu.md` (piliers, convictions, sources), `posts-de-reference.md` (vos posts, pour caler la voix), `swipe-file.md` (les posts des autres, pour les structures).

Ne va pas ici : les messages de prospection envoyés en DM (`05_Departements/Go-to-Market/Messages/`), la source qui a inspiré le post (`08_Ressources/Veille/sources/`).

## Cadre

Un post par fichier : `Post-Sujet_YYYY-MM-DD.md`. Le brief de veille hebdo : `Brief-veille_YYYY-MM-DD.md`. Une infographie : `Infographie-Sujet_YYYY-MM-DD.md` (le brief) et `.png` (l'image), produits par le master `infographie` à partir de `03_Branding/charte-visuelle.md`. Les sources (transcripts, articles, idées brutes) dans `sources/`.

Les posts qui ont bien marché remontent dans `posts-de-reference.md`. Les posts des autres qui arrêtent le scroll vont dans `swipe-file.md`. Plus l'échantillon est riche, plus la voix est juste.

- à plat : les posts, les briefs et les infographies, plus `strategie-contenu.md`, `posts-de-reference.md`, `swipe-file.md`
- `sources/` transcripts, articles, idées brutes à repurposer

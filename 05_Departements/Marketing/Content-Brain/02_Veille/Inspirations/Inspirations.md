# Inspirations

> Les posts des autres qui vous arrêtent : ceux des créateurs que vous suivez et ceux que vous sauvegardez. Une fiche par post, au format décrit dans `10_Skills/_commun/content-brain.md`. Les skills s'en servent pour les structures, les hooks et les angles, jamais pour les mots.

Chaque fois qu'un post vous arrête, collez-le dans le chat avec "ajoute cette inspiration". Le sous-skill `veille-createurs` propose aussi des fiches après chaque run, sur un oui.

## Ce qu'on emprunte et ce qu'on ne copie pas

Emprunter : les structures (avant/après, liste avec sous-points, hook puis arguments), les patterns de hooks, les marqueurs visuels, l'angle d'un sujet.

Ne jamais copier : les mots exacts, les histoires personnelles d'un autre, des chiffres qui ne sont pas les vôtres, le positionnement d'une autre personne.

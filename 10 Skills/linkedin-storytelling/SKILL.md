# LinkedIn Storytelling

**Prérequis** : Lis d'abord `../linkedin-writing-core/SKILL.md` pour les règles fondamentales de voix, formatage et qualité. Ce skill les complète avec les techniques narratives spécifiques.

## Quand utiliser ce skill

Ce skill couvre tous les posts basés sur une narration personnelle :
- **Backstory** : parcours personnel, origines, décisions marquantes
- **Transformation** : avant/après, pivots, changements majeurs
- **Build in public** : coulisses de ce que le créateur construit, transparence
- **Leçons apprises** : apprentissages tirés d'expériences vécues
- **Portrait** : mise en lumière d'une personne inspirante
- **Voyage / lifestyle** : expériences qui nourrissent la réflexion professionnelle

## L'approche storytelling de le créateur

Le créateur ne fait PAS du storytelling à la "LinkedIn bro". Son approche est :
- **Factuelle** : il raconte ce qui s'est passé, pas ce qu'il a ressenti à chaque instant
- **Structurée** : même une histoire suit une progression logique
- **Utile** : chaque histoire mène à un apprentissage concret
- **Honnête** : il partage aussi les doutes et les échecs, sans excès de pathos

Ce n'est pas du storytelling hollywoodien. C'est quelqu'un qui dit : "Voilà ce que j'ai vécu, voilà ce que j'en retiens."

> Adapte le ton à `les marqueurs de ton de `02 Contexte/Tone-and-Voice.md`` et garde le lien avec sa niche (voir `05 Departements/Contenu/LinkedIn/strategie-contenu.md`).

## Les 6 formats narratifs

### 1. Le Backstory
Raconte un moment clé du parcours de le créateur et le relie au présent.

**Structure** :
```
HOOK → Fait marquant + date ou contexte
BACKSTORY → Ce qui s'est passé (chronologique, concis)
LIEN → Comment ça se connecte à aujourd'hui
LEÇONS → 3-5 apprentissages concrets
CONCLUSION → Phrase de fermeture + question
```

**Règle clé** : Le backstory doit toujours avoir un lien avec le contexte actuel de le créateur (sa niche (voir `05 Departements/Contenu/LinkedIn/strategie-contenu.md`)). Pas d'histoire "pour l'histoire".

**Hooks typiques** :
- "Il y a [X] ans, j'ai [décision]. Aujourd'hui, [résultat]."
- "En [date], je [situation initiale]. [X] ans plus tard, [situation actuelle]."
- "À [âge], j'ai pris une décision radicale : [décision]."

### 2. La Transformation
Crée un contraste fort entre un "avant" et un "après".

**Structure** :
```
HOOK → Contraste temporel fort (2 dates, 2 situations)
AVANT → La situation de départ (problème, difficulté)
POINT DE BASCULE → Ce qui a changé (décision, événement)
APRÈS → La situation actuelle (résultat)
CE QUI A FAIT LA DIFFÉRENCE → Les actions clés
CONCLUSION → Synthèse + question
```

**Hooks typiques** :
- "En [date 1], je [situation avant]. En [date 2], [résultat après]."
- "Il y a [X] mois, je [problème]. Aujourd'hui, c'est différent."
- "Avant : [situation avant]. Après : [situation après]. Voici ce qui a changé."

### 3. Le Build in Public
Partage les coulisses de ce que le créateur construit en temps réel.

**Structure** :
```
HOOK → Annonce de ce qui se passe
CONTEXTE → Pourquoi le créateur fait ça
CE QUI A ÉTÉ FAIT → Étapes, décisions, résultats intermédiaires
CE QUI VIENT → Prochaines étapes
INVITATION → Embarquer l'audience dans le voyage
```

**Ton** : Plus décontracté, presque conversationnel. L'audience est "embarquée dans l'aventure".

**Hooks typiques** :
- "On vient de [accomplissement]. Et on a décidé de tout vous partager."
- "Depuis [X] mois, je construis [chose]. Voici les coulisses."
- "Grosse nouvelle : [annonce]. 👇"

### 4. Les Leçons Apprises
Distille les apprentissages d'une expérience spécifique.

**Structure** :
```
HOOK → Contexte de l'apprentissage + nombre de leçons
CONTEXTE RAPIDE → Ce qui s'est passé (3-4 lignes max)
LEÇONS → Numérotées, chacune en 1-3 lignes
CONCLUSION → Leçon bonus ou réflexion finale
```

**Règle** : Chaque leçon doit être actionnable ou au minimum réfléchissante. Pas de platitudes.

**Hooks typiques** :
- "J'ai [action] pendant [X] mois. Voici mes [Y] apprentissages."
- "Après [expérience], voici ce que j'aurais aimé savoir avant."
- "[X] leçons que j'ai apprises en [activité]. La [Y]e a tout changé."

### 5. Le Portrait
Met en lumière une personne, un client, un partenaire.

**Structure** :
```
HOOK → Fait marquant sur la personne
CONTEXTE → Qui est cette personne, que fait-elle
SON PARCOURS → Les moments clés de son histoire
CE QU'ON PEUT EN RETENIR → Leçons universelles
CONCLUSION → Message large qui touche toute l'audience
```

**Règle** : À la fin du portrait, le créateur tire toujours un message plus large qui résonne avec son audience. Le portrait n'est pas qu'une hagiographie, il sert un propos.

### 6. Le Voyage / Lifestyle
Partage une expérience de vie qui nourrit la réflexion professionnelle.

**Structure** :
```
HOOK → L'expérience en une phrase
LE MOMENT → Description concise de l'expérience
LA RÉFLEXION → Ce que ça inspire pour le business/la vie
LE LIEN → Connexion avec le quotidien de l'audience
CONCLUSION → Question ou invitation à partager
```

**Ton** : Plus léger, inspirant sans être "coach de vie". Le créateur partage un moment, pas un sermon.

## Techniques narratives spécifiques

### L'open loop
Créer une boucle ouverte dans le hook qui ne se referme que plus loin dans le post.
```
"[Date], on clôturait [un résultat business].
Sur le papier, tout allait bien.
À un détail près (très important) :"
```
Le lecteur DOIT cliquer "voir plus" pour savoir quel est ce détail.

### Le contraste temporel
Juxtaposer deux réalités pour créer une tension narrative.
```
"Il y a [X] ans, je ne savais pas [compétence].
Aujourd'hui, [résultat lié à cette compétence]."
```

### La chute inattendue
Construire une attente puis la déjouer.
```
"On a travaillé [X] mois sur ce lancement.
Résultat ? [résultat décevant].
[...mais finalement, voici ce qui s'est passé]"
```

### Le retour au concret
Après chaque moment émotionnel, revenir au concret.
```
"Ce moment m'a fait réaliser quelque chose d'important.
Concrètement, voici ce que j'ai changé :"
```

## Erreurs spécifiques au storytelling

- **Trop de pathos** : le créateur ne s'apitoie pas. Il constate, il apprend, il avance.
- **Histoire sans leçon** : Chaque histoire doit mener quelque part d'utile.
- **Backstory déconnectée** : Si l'histoire n'a aucun lien avec sa niche (voir `05 Departements/Contenu/LinkedIn/strategie-contenu.md`), elle n'a pas sa place.
- **Dramaturgie artificielle** : Ne pas inventer de tension là où il n'y en a pas. Rester factuel.
- **Trop long** : Le storytelling LinkedIn n'est pas un roman. Garder la narration serrée.
